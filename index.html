Why “fundamental” differs from “total”

The chessboard has eight symmetries (four rotations combined with mirror reflections). Two solutions that map onto each other under one of these symmetries are considered the same fundamental solution. For the classic n = 8 board, the 92 total solutions collapse into only 12 fundamental ones — an observation first worked out in the 1870s.

1. The rules

Place n queens on an n × n board so that no two share a row, a column, or a diagonal. In symbols, queens at (r₁,c₁) and (r₂,c₂) must satisfy r₁ ≠ r₂, c₁ ≠ c₂ and |r₁ − r₂| ≠ |c₁ − c₂|.

2. Backtracking = DFS + pruning

We fill the board one row at a time. In each row we probe columns left to right; the first conflict-free column gets a queen and we recurse. If no column fits we backtrack: undo the previous placement and continue with its next candidate. Pruning cuts entire subtrees as soon as one constraint fails.

3. O(1) conflict checks

Instead of scanning the board, three occupancy flags answer “is this square safe?” in constant time: cols[c] for columns, diag1[r−c+n−1] for ↗ diagonals and diag2[r+c] for ↘ diagonals. Every cell on the same diagonal shares the value of r−c (or r+c).

The algorithm — generator-based backtracking

This is the actual source powering the animation (a plain-JS port of the TypeScript engine in nextjs/src/lib/nqueens.ts). Each search action yields one event, which the player applies forward or reverses backward.

// One generator drives the whole search: it yields an atomic
// event for every probe, conflict, placement, retraction and
// completed solution. Conflict checks are O(1) with three flags.
function* createSolver(n) {
  const queens = new Int8Array(n).fill(-1);
  const cols = new Uint8Array(n);
  const diag1 = new Uint8Array(2 * n - 1); // row - col + n - 1
  const diag2 = new Uint8Array(2 * n - 1); // row + col

  function* place(row) {
    if (row === n) {
      yield { type: 'solution', row: n - 1, col: queens[n - 1] };
      return;
    }
    for (let col = 0; col < n; col++) {
      yield { type: 'try', row, col };
      if (cols[col] || diag1[row - col + n - 1] || diag2[row + col]) {
        yield { type: 'conflict', row, col };
        continue;
      }
      queens[row] = col;
      cols[col] = 1;
      diag1[row - col + n - 1] = 1;
      diag2[row + col] = 1;
      yield { type: 'place', row, col };
      yield* place(row + 1);
      queens[row] = -1;
      cols[col] = 0;
      diag1[row - col + n - 1] = 0;
      diag2[row + col] = 0;
      yield { type: 'backtrack', row, col };
    }
  }

  yield* place(0);
}

// Counting variant: three bitmasks, no board at all. The classic
// trick — (ld << 1) shifts the left-diagonal attack zone one
// square leftward on each step down.
function countSolutions(n) {
  if (n === 0) return 1;
  const full = (1 << n) - 1;
  const solve = (cols, ld, rd) => {
    if (cols === full) return 1;
    let count = 0;
    let avail = full & ~(cols | ld | rd);
    while (avail) {
      const bit = avail & -avail;
      avail ^= bit;
      count += solve(cols | bit, ((ld | bit) << 1) & full, (rd | bit) >> 1);
    }
    return count;
  };
  return solve(0, 0, 0);
}

Search-space sizes

  • Arbitrary placement: C(n², n) ≈ n2n / n! boards
  • One queen per row: nⁿ candidates
  • One per row and column (a permutation): n!
  • After diagonal pruning, the explored tree is far smaller — e.g. 2,057 nodes for n = 8 versus 8! = 40,320 permutations.
